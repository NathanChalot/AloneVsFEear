## Character sheet

The sheet is a form: this file lists its fields from top to bottom, without their artwork.

| Field | Shape on the sheet | Notes |
| --- | --- | --- |
| Name | text box | |
| XP | number box | |
| Sanity | number box | single box: current and max are not separated |
| Life | number box | single box: current and max are not separated |
| Clues | number box | |
| Injuries | large free-text box | the pregenerated sheets label the same box "Injuries" |
| Insanities | large free-text box | the pregenerated sheets label it "Mental scars" |
| Keywords | one line | flags such as CLOWNFACE and SNOWY |
| Skills | about 9 ruled lines | |
| Weapons | free-text box | |
| Ammo | small number box | one box, not one per ammo type |
| Arcane Skills | about 2 lines | |
| Food | white circle (counter) | in the left margin |
| Candles | white circle (counter) | in the left margin; candles are counted like Food, not as items |
| Equipment | about 16 ruled lines | |
| Books read | about 3 lines | |

Footer: "Permission granted to reproduce this sheet for personal use only © Ganesha Games, 2020".

### What the sheet does not show

Things the rules track that have no field: Safe House stashes (written on the town map), the box number (written on the town map), the backpack and carry limits, the mission. Encumbrance is in the [encumbrance summary](11_encumbrance_summary.md).
